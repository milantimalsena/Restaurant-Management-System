# 🍽️ Smart Restaurant Management System

A modern full-stack **Restaurant Management System** developed using **Java Servlets, JSP, JDBC, MySQL, JSTL, and Tailwind CSS** following the **MVC Architecture Pattern**.

This system provides a complete digital restaurant solution including:

- 🍔 Online Food Ordering
- 🛒 Cart & Checkout
- 💳 QR Payment System
- 🪑 Table Reservation
- 📦 Order Tracking
- 📊 Admin Dashboard
- ⭐ Feedback & Ratings
- 🔐 Authentication & Authorization

---

# 📸 System Overview

The application contains two major modules:

## 👤 Customer Portal
Customers can:
- Register/Login
- Browse Menu
- Add Food to Cart
- Checkout Orders
- Reserve Tables
- Track Orders
- View Payment QR
- Submit Feedback

---

## 🛠️ Admin Portal
Admins can:
- Manage Menu
- Manage Orders
- Verify Payments
- Upload Payment QR
- Manage Reservations
- Manage Tables
- View Reports & Analytics
